PASOS PARA CAMBIAR UNA IMAGEN:
------------------------------
  1. Toma la foto del producto (con buena luz, fondo limpio).
  2. Recórtala cuadrada (700 x 700 px recomendado).
  3. Guárdala como .jpg con calidad alta.
  4. Renómbrala con el nombre EXACTO de la lista abajo.
  5. Cópiala dentro de esta carpeta (img/) reemplazando la actual.
  6. Refresca la página en el navegador. ¡Listo!

RECOMENDACIONES PARA LAS FOTOS
================================================================

  • Tamaño productos:   700 x 700 px (cuadrado)
  • Tamaño banners:     900 x 675 px (horizontal)
  • Formato:            .jpg (calidad 85-90%)
  • Fondo:              Blanco o neutro de preferencia
  • Iluminación:        Natural o con softbox, sin sombras duras
  • Encuadre:           Producto centrado, con margen alrededor

================================================================
TIPS RÁPIDOS
================================================================

  ✓ Si NO renombras el archivo igual, la página no la encontrará.
  ✓ El nombre debe ser EXACTAMENTE igual (minúsculas, con _).
  ✓ Borra la imagen vieja antes de pegar la nueva (o pega y
    Windows preguntará si reemplazar — di que sí).
  ✓ Después de cambiar la imagen, presiona Ctrl + F5 en el
    navegador para forzar la recarga sin caché.
