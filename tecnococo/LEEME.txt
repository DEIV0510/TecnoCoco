COMO USAR
---------
1. Abre "index.html" en tu navegador (doble click) — la página funciona localmente.
2. Para subirla a internet, sube TODA la carpeta "tecnococo/" a tu hosting
   (Hostinger, Netlify, Vercel, GitHub Pages, etc.).

REEMPLAZAR EL LOGO POR EL REAL
------------------------------
1. Guarda tu logo del coco dorado con audífonos como "logo.png".
2. Cópialo dentro de la carpeta "logo/" reemplazando el archivo actual.
3. Tamaño recomendado: 512 x 512 px, formato PNG.
   (Mira el archivo "logo/LEEME-LOGO.txt" para más detalles.)

REEMPLAZAR LAS IMÁGENES DE PRODUCTO POR FOTOS REALES
-----------------------------------------------------
Las imágenes en "img/" son placeholders (negro + dorado). Cuando tengas
las fotos reales:

  1. Toma la foto de cada producto.
  2. Guárdala con EXACTAMENTE el mismo nombre del placeholder (por ejemplo
     "airpods-pro-2.jpg") en la carpeta "img/".
  3. Refresca el navegador — tu foto aparecerá automáticamente.

Tamaños recomendados:
  - Productos (cuadrados):     700 x 700 px
  - Categorías y banner:       900 x 675 px
  - Foto "Nosotros":           800 x 1000 px (vertical)
  - Hero (audífonos destacado): 900 x 900 px

Formato sugerido: JPG con calidad 85-90% (o PNG si necesitas transparencia).
