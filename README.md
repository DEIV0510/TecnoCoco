# 🥥 TecnoCoco

Tienda online de **accesorios y gadgets de tecnología** en Colombia: audífonos, AirPods, cargadores, aros de luz, power banks y más. Envío gratis a todo el país, garantía y pago contra entrega.

🔗 **Pedidos por WhatsApp:** [+57 310 549 0250](https://wa.me/573105490250) · ✉️ hola@tecnococo.co

---

## ✨ Características

- **Catálogo de 12 productos** con modal de detalle (especificaciones, valoraciones, productos relacionados).
- **Buscador en vivo** (ignora tildes, navegable con teclado).
- **Carrito de compras** con cantidades y persistencia local, que arma el pedido completo y lo envía por **WhatsApp**.
- **Favoritos** guardados en el navegador.
- **SEO + datos estructurados (Schema.org / JSON-LD)**: Open Graph, Twitter Card y rich snippets de productos y FAQ.
- **Accesible (WCAG AA)**: navegación por teclado, focus visible, `prefers-reduced-motion`, roles ARIA.
- **Responsive** y optimizada (lazy-loading, placeholder de marca para imágenes faltantes).

## 🛠️ Tecnología

Un solo archivo `index.html` (HTML + CSS + JavaScript, sin dependencias ni build). Paleta negro `#0b0b0c` + dorado `#c9a24b`. Tipografías Inter + Playfair Display.

## 🚀 Uso

1. **Local:** abre `index.html` con doble clic en el navegador.
2. **En internet:** sube toda la carpeta a cualquier hosting estático (Netlify, Vercel, GitHub Pages, Hostinger…).

### GitHub Pages
`Settings → Pages → Branch: main → /(root)`. La tienda quedará publicada en `https://deiv0510.github.io/TecnoCoco/`.

## 🖼️ Imágenes

Las fotos de producto van en `img/` con nombres fijos (`p_*.jpg`). Los productos nuevos vienen de Dropi con las fotos del proveedor, recortadas y optimizadas.

## ⚙️ Personalización

- **Dominio SEO:** en `<head>` busca `https://tecnococo.co` y reemplázalo por tu dominio real.
- **Precios / textos:** edita `index.html` (objeto `PRODUCTS` para datos de producto).
- **WhatsApp:** el número aparece como `573105490250`.
